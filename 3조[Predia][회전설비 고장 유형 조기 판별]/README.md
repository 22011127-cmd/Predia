# Predia
code
실행 방법
1. data 파일에 분석하고자 하는 data set를 저장함
2. 1_data_analysis에 해당 파일의 경로를 작성하고 실행시켜 데이터 분석 및 그래프를 확인
3. 2_model를 실행하여 해당 data set에서 사용할 수 있는 model를 생성
4. 출력된 정확도,재현율,정밀도 등의 데이터로 model 평가

데이터 출처 
https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset

팀원과 역활
데이터 분석 - 원종준
시계열/특성 분석 - 송지호
모델링 - 한재민, 한찬희
해석/문서 작성 - 김예민
